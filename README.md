# 🎰 Casino.fun

**Крипто-казино платформа, где любой может за 60 секунд запустить свою казино-комнату!**

## 🎯 Описание

Casino.fun — это платформа, где пользователи могут:
- 🎲 Создавать свои собственные казино-комнаты с настройками (тема, house edge, время жизни)
- 💰 Зарабатывать на house edge и обороте своих комнат
- 🎮 Играть в coinflip в любых комнатах
- 📊 Смотреть статистику и лидерборды
- 🤖 Наслаждаться живой активностью благодаря бот-движку

## 🏗️ Архитектура

### Backend
- **Flask** — Python веб-фреймворк
- **SQLAlchemy** — ORM для работы с БД
- **SQLite** — база данных
- **Flask-CORS** — поддержка CORS

### Frontend
- **React** — UI библиотека
- **Vite** — сборщик
- **React Router** — роутинг
- **Axios** — HTTP клиент

### Фичи
- ✅ Создание комнат с настройками
- ✅ Coinflip игра
- ✅ Демо-режим (виртуальные деньги)
- ✅ Система house edge
- ✅ Таймер жизни комнат
- ✅ История ставок
- ✅ Лента глобальных событий
- ✅ Бот-движок для генерации активности
- ✅ Реферальная система (готовая структура)
- ✅ Лидерборды

## 🚀 Быстрый старт

### 1. Установка зависимостей

#### Backend
```bash
cd backend
pip install -r requirements.txt --break-system-packages
```

#### Frontend
```bash
cd frontend
npm install
```

### 2. Запуск приложения

#### Терминал 1: Backend
```bash
cd backend
python app.py
```
Backend будет доступен на `http://localhost:5000`

#### Терминал 2: Bot Engine (опционально)
```bash
cd backend
python bot_engine.py
```
Бот-движок создаст комнаты и начнёт генерировать ставки

#### Терминал 3: Frontend
```bash
cd frontend
npm run dev
```
Frontend будет доступен на `http://localhost:5173`

## 🎮 Механики

### Создание комнаты
- Название (любое)
- Тема: Prison, Cartel, Virus, Degen Pit, Cyber Club
- House Edge: 1-5%
- Время жизни: 12-48 часов

### Coinflip игра
- Выбор суммы и стороны (HEADS/TAILS)
- Максимальная ставка: 5% от банкролла комнаты
- House edge применяется к выигрышам
- Мгновенный результат

### Экономика
- **Хост зарабатывает** на house edge (в долгосрочной перспективе банкролл растёт)
- **Платформа берёт** комиссию с оборота (модель заложена, в демо не активна)

## 🤖 Бот-движок

Бот-движок автоматически:
- Поддерживает 10 активных комнат
- Создаёт бот-пользователей и бот-комнаты
- Генерирует ставки с разными стилями (консервативные, агрессивные, киты)
- Истекает старые комнаты
- Создаёт события для глобальной ленты

Интервал работы: 30 секунд по умолчанию

## 📡 API эндпоинты

### Комнаты
- `GET /api/rooms` — список комнат
- `GET /api/rooms/<code>` — детали комнаты
- `POST /api/rooms` — создать комнату
- `POST /api/rooms/<code>/bet` — сделать ставку
- `GET /api/rooms/<code>/bets` — история ставок

### События и статистика
- `GET /api/events` — глобальная лента событий
- `GET /api/leaderboard` — лидерборды
- `GET /api/stats` — глобальная статистика
- `GET /api/users/<id>` — профиль пользователя
